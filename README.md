# Student Management System

A simple student management system developed using Python and SQL.

## Project Description

This project manages student records using Python and an SQL database.

## Technologies Used

- Python
- SQLite
- SQL
- GitHub

## Features

- Add students
- View students
- Search for students
- Delete students
- Store student information

## How to Run

1. Install Python 3.
2. Open the project folder.
3. Run `python student_management.py`.
